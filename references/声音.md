# 声音：用代码合成配乐、对齐画面、检查

> 出处：IntroFree 的配乐脚本（鼓、音色、效果、侧链、混响、母带）和北海片（木琴、环境声）。原理和坑见 [动效.md](动效.md) 第 5–7 节；这里讲怎么用 `library/audio/synth.ts`。

## 怎么用

```ts
import { createSynth } from "../src/lib/audio/synth.ts";
import { B, bar, DURATION, FPS, T } from "../src/film/timeline.ts";

const s = createSynth({ seconds: DURATION / FPS, fps: FPS });
s.cleanCuts.push(T.stop);           // 这一帧之前的声音在这里收干净（20 ms 淡出）
s.kick(bar(2), 0.6);                // 每个声音都放在帧号上，和画面读同一份时间表
s.pad(bar(2), bar(4), [62, 66, 69], 0.04, 2000);
s.whoosh(T.pan - 9, 0.3, 0.6);      // 甩镜：风声的中点放在甩得最快的时候
const mix = s.mixdown();            // 低音和音乐在底鼓下压低（侧链），主输出 32 Hz 高通
s.silence(mix, T.stop, T.restart);  // 计划内的静音是真正的数字静音
s.master(mix, -1);                  // 软限幅后归一到 −1 dBFS
writeFileSync("public/audio/film.wav", s.toWav(mix));
```

起步模板的 `starter/scripts/gen-audio.ts` 是一个完整例子。

## 有哪些声音

| 类别 | 函数 | 备注 |
| --- | --- | --- |
| 鼓 | `kick` `heartbeat` `clap` `snare` `hat` `shaker` `tick` | 底鼓自带 1.8 kHz knock 和 click，手机外放也听得到；`tick` 给安静段的重音用 |
| 音色 | `pluck` `marimba` `piano` `bell` `pad` `supersaw` `lead` `bassNote` | 音高用 MIDI 号（60 = 中央 C）；贝斯有高八度的锯齿，小喇叭也听得到 |
| 效果 | `typeClick` `blip` `whoosh` `impact` `crash` `glitch` `riser` `swell` `chime` | `swell` 在终点前 40 ms 掐断，下一拍的起音才干净；`riser` 不掐 |
| 环境（北海片） | `waves` `gull` `horn` `templeBell` `crickets` `murmur` `engine` `sizzle` | 噪声类都已经加了低通 |
| 混音 | `mixdown` `tapeStop` `silence` `fadeOut` `master` `toWav` | 顺序：mixdown → tapeStop／silence → fadeOut → master |

自己写新声音：`s.put(bus, 帧, 秒数, 音量, 声像, (t, i) => 样本)`，滤波用 `new s.SVF()`，锯齿用 `new s.Saw()`，滑音用 `s.glide()`。随机数用 `s.rnd()`（固定种子，每次生成的 WAV 一样）。

## 规矩

- 画面上每一次跳变（甩镜、砸字、切换），同一帧都要有一个清楚的起音；`tools/check-av.ts` 的第 [6] 项会把“没有声音的跳变”找出来。起步模板第一次检查就抓到一处：摄像机甩向地点的那一拍没有声音。
- 长尾的声音（混响、铃、琶音）会盖住下一个重音：要么把切点放进 `cleanCuts`，要么用 `swell` 代替 `riser`。
- 用噪声做的声音一定要低通，北海片的海浪、人声、风声在频谱上一直到 24 kHz 都是嘶声。
- 北海片的配乐没照这些做（底鼓没有 knock、贝斯叠了低八度正弦、没有 32 Hz 高通），手机外放可能显得闷，没人听过。本库的 `synth.ts` 已经按 IntroFree 的做法改过。

## Claude 听不到，只能量

- 整体响度：`ffmpeg -i x.wav -af ebur128=framelog=quiet -f null -`，网络平台一般在 −14 LUFS 左右（北海片 −14.1，起步模板 −14.0）。
- 频谱：`ffmpeg -i x.wav -lavfi "showspectrumpic=s=1600x600:legend=1:scale=log" spec.png`，看有没有一直到顶的嘶声、有没有奇怪的高频泛音。
- 对齐和削波：`tools/check-av.ts out/film.mp4 check.json`（在 check.json 里写重点动作的帧号、计划内的静音、分段）。
- 交付时说明：这些只证明“时间对、不削波、响度合适”，好不好听要 JIN 听。
