# 代码目录（library/）

`tools/new-film.sh` 会把整个 `library/` 复制到新项目的 `src/lib/`。都是从 JIN-motion- 的片子里拆出来、在起步模板里实测渲染过的。缩略图在 `assets/catalog/`（起步模板里的 `Gallery` 合成就是这张目录，渲第 `页号 × 60 + 30` 帧即可看到那一页）。

## core：所有片子都会用

| 文件 | 内容 | 来源 |
| --- | --- | --- |
| `core/math.ts` | `clamp` `lerp` `inv` `easeIn/Out/InOut` `springAt`（解析解弹簧，小数帧也准）`whip`（踩拍曲线）`pop`（踩拍出现）`hash` `noise1`（确定性随机） | Intro、IntroFree |
| `core/beat.ts` | `makeBeatGrid({ bpm, fps, minDivision })` → `B(拍)` `S(步)` `bar(小节, 拍)` `sampleAt(帧)`；网格落在帧之间会直接报错 | IntroFree |
| `core/MotionBlur.tsx` | `Blur`（按偏移量取子帧平均）、`MotionBlur`（N 次居中采样）、`shutterOffsets(帧, 重拍帧, 切点)`（只在重拍后几帧开、不跨切点） | Intro、IntroFree |
| `core/text-width.ts` | `textWidth` `charWidth` `isWide`：不读 DOM 估算中英混排宽度 | IntroV2、IntroFree |

## tools（复制到新项目的 `scripts/`）

| 文件 | 用途 |
| --- | --- |
| `tools/new-film.sh <目录>` | 建新项目：起步模板＋library＋tools |
| `tools/fetch-fonts.ts` | 按 `ALL_TEXT` 下载字体切片 |
| `tools/render-stills.ts <合成> <目录> 帧,帧,…` | 打包一次连出多帧静帧 |
| `tools/contact-sheet.py` | 静帧或成片拼图，每格标时间和帧号 |
| `tools/check-av.ts <成片> [check.json]` | 削波、静音段、响度、重点动作的声音和画面、盲测跳变 |
| `tools/coast-extract.py` | 从 Natural Earth 裁海岸线 |
