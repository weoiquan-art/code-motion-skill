# 通用经验：开工前、环境、字体、渲染与查看、文案

> 出处：JIN-motion- 的 IntroFree 和北海宣传片。标“（北海片）”的是北海片补的。单条片子的经验，不是定律。

## 开工前（北海片）

- JIN 的需求常常只有一句（北海片：“帮我做一个槟城北海的宣传片 所有元素你定”），JIN 也说过“说话可能抽象，请先问完整意思”。先用选择题问三项：做成什么（代码动画成片／AI 视频提示词包／两者结合）、画幅和时长、画面文字的语言。北海那次推荐的是 9:16 竖屏 30 秒，JIN 选了 16:9 横屏 60 秒，默认值不一定猜得对。
- 画面里写出来的数字、专名、史实都要查到来源并记进案例；查不到就不写数字，或者先问 JIN。北海片的“第二大桥 24 km”是凭记忆写的，就是反例。
- “所有元素你定”时，主题、结构、场景、配乐都由 Claude 定，交付时要把这些决定写清楚，JIN 才能改。

## 环境（claude.ai 云端容器，实测）

- Remotion 4.0.532，Node 22 直接跑 `.ts` 脚本（`node --disable-warning=MODULE_TYPELESS_PACKAGE_JSON scripts/x.ts`）。被脚本 import 的文件不能依赖 React／Remotion，import 路径要写 `.ts` 后缀。
- 浏览器用容器里现成的 headless shell：`--browser-executable=/opt/pw-browsers/chromium_headless_shell-1194/chrome-linux/headless_shell`。不要跑 `playwright install`。
- 下载东西走代理：Node 的 fetch 要加 `NODE_USE_ENV_PROXY=1`（字体脚本已经写进 `npm run fonts`）。
- 渲染速度参考：1920×1080 扁平插画，1,800 帧约 3 分钟；起步模板 448 帧约 40 秒。

## 字体

- 云端渲染浏览器访问不了 fonts.gstatic.com，字体要放 `public/fonts/`，用 `@remotion/fonts` 的 `loadFont()`。它自带 `delayRender()`，字体没加载完不会出帧；文件缺失会直接报错。
- Noto Sans SC／Noto Serif SC 按 unicode-range 切成约 100 片，只下载文案用到的切片（`tools/fetch-fonts.ts`）。改了文案要重新跑。
- 标题用 Noto Serif SC，标签用 Noto Sans SC，英文用 Inter（“机器”感的字用 JetBrains Mono）。中文字体注册时去掉 ASCII 区段（`withoutAscii`），英文和数字一定走 Inter，“，”“——”这类全角标点仍由中文字体画。`library/fonts/fonts.ts` 的 `registerFonts(ALL_TEXT)` 一次做完。
- 坑（北海片）：画面上的字没写进 `ALL_TEXT`，对应的切片根本不会注册，这个字会悄悄落到系统字体或显示成方框，不会报错。

## 渲染与查看

- 渲染整片：`npm run render:cloud -- <Composition> out/<名字>.mp4`。
- 开发时别每次渲整片，也别一帧一帧跑 `remotion still`（每次都重新打包，慢）：用 `tools/render-stills.ts` 打包一次连出多帧，再用 `tools/contact-sheet.py` 拼成一张、每格写上时间和帧号。
- 成片抽帧按帧号：`ffmpeg -i out.mp4 -vf "select=eq(n\,FRAME)" -vframes 1 kFRAME.png`（不要用 `-ss` 秒数，会差一帧）。
- 看什么：每个场景中间一帧、每个转场中间一帧、开头结尾。整片的节奏和动作顺不顺，静帧看不出来，交付时要说明。

## 文案

- 所有会变的字放在一个时间表文件里（`timeline.ts` 或 `content.ts`），画面、配乐脚本、字体脚本都读它。
- 中文阅读速度按每秒 4–5 个字估；一句话在屏幕上停留的时间要够读完。“节奏太快”的感觉多半来自这里，而不是 BPM。
- 先定标题安全区，再摆道具（北海片）。北海片的标题在左下，前后有 5 处道具压到标题（码头浮球、猫和桌凳、单车和盆栽、香炉、渡轮），都是看静帧才发现的。
- 100 px 的中文标题一行不超过 10 个字（北海片）。“1894 年至今，渡轮往返两岸”一行约 1,250 px，改成“百年渡轮，往返两岸”，数字放进英文副标题。
- 亮的画面上压白字：加 `BottomScrim`（`library/ui/backdrop.tsx`）和文字阴影。

## 交付

- `npm run lint` → 渲染 → 抽帧检查 → `tools/check-av.ts` → 提交推送 → 把成片发给 JIN。
- `out/` 通常在 `.gitignore` 里，成片要 `git add -f`，和 wav、新下载的字体一起提交；单个文件小于 100 MB。
- 说清楚哪些没核验：配乐没人听过、整片没人从头看过、画面里哪些事实没查到来源。
